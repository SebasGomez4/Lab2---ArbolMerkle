# ¿ Que se hizo ?
Dentro del laboratorio #2 se hizo uso de un árbol de Merkle utilizando el algoritmo de hashing de SHA256. Dentro del código el usuario podrá verificar la capacidad de generar N transacciones y obtener la raíz merkle, además de manera manual podrá crear las transacciones y se construira un árbol de forma ASCII a partir de los 8 primeros digitos de cada hoja, finalmente el usuario podrá verificar con una prueba de inclusión si la transacción es igual o no
